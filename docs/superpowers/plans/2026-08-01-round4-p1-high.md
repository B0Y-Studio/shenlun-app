**Context for implementer:** Currently `useEffect(() => { loadPapers(); }, [loadPapers])` re-fires on every keystroke (`yearFilter` is a dep of `loadPapers`). Typing "2025" causes 4 API calls + 4 list re-renders + race conditions. Debounce defers the API call until 400ms after the user stops typing.

- [ ] **Step 1: Create `src/hooks/useDebouncedValue.ts`**

```ts
// src/hooks/useDebouncedValue.ts
import { useState, useEffect } from 'react';

export function useDebouncedValue<T>(value: T, delayMs: number): T {
  const [debounced, setDebounced] = useState(value);
  useEffect(() => {
    const t = setTimeout(() => setDebounced(value), delayMs);
    return () => clearTimeout(t);
  }, [value, delayMs]);
  return debounced;
}
```

## Task 4: H1 — SSE abort handling + reader.releaseLock + JudgeScreen catch

**Files:**
- Modify: `src/llm/client.ts` (wrap reader loop in try/catch/finally with `reader.releaseLock()`)
- Modify: `src/screens/JudgeScreen.tsx` (add `catch` around the `for await` loop)

**Interfaces:**
- Consumes: `runJudge` async generator; `AbortController.signal` passed via opts
- Produces: SSE reader releases lock on cancel/finish; AbortError is silently absorbed by `runJudge`; non-Abort stream errors yield `{type: 'error'}`; JudgeScreen.onStart handles propagated errors gracefully

**Context for implementer:** Two coupled bugs:
1. When user clicks "取消" (cancel button) or screen unmounts during streaming, `AbortController.abort()` rejects the in-flight `reader.read()`. Current code has no try/catch around this read loop — the rejection becomes an "unhandled promise rejection" in the parent.
2. `reader.releaseLock()` is never called — TCP connection and reader lock leak.

The fix has TWO coordinated changes:
- `client.ts` (line 95-145): wrap the read loop in try/catch/finally, with AbortError absorbed (caller knows it cancelled; no error event needed).
- `JudgeScreen.tsx` (line 59-91): add `catch` after the `try { for await } finally` to handle non-Abort propagations.

- [ ] **Step 2: Wrap reader loop in try/catch/finally in `client.ts`**

Edit `src/llm/client.ts`. Find the block (currently no try/catch around the while loop). Replace with:

```ts
  const decoder = new TextDecoder('utf-8');
  let buf = '';
  let fullText = '';
  try {
    while (true) {
      const { value, done } = await reader.read();
      if (done) break;
      buf += decoder.decode(value, { stream: true });
      let nl: number;
      while ((nl = buf.indexOf('\n\n')) >= 0) {
        const evt = buf.slice(0, nl);
        buf = buf.slice(nl + 2);
        const line = evt.split('\n').find(l => l.startsWith('data:'));
        if (!line) continue;
        const payload = line.slice(5).trim();
        if (payload === '[DONE]') {
          const result = safeParseJudgeResult(fullText);
          yield { type: 'result', result, raw: fullText };
          return;
        }
        try {
          const obj = JSON.parse(payload);
          if (obj.error) {
            yield { type: 'error', code: 'upstream', message: String(obj.error) };
            return;
          }
          if (typeof obj.delta === 'string') {
            fullText += obj.delta;
            opts.onDelta?.(obj.delta);
            yield { type: 'delta', text: obj.delta };
          }
        } catch {
          // 忽略非 JSON 行
        }
      }
    }
  } catch (e) {
    // AbortError 是用户主动取消，静默；其它错误上报
    if (!(e instanceof Error && e.name === 'AbortError')) {
      yield { type: 'error', code: 'stream', message: e instanceof Error ? e.message : String(e) };
    }
    return;
  } finally {
    try { reader.releaseLock(); } catch { /* ignore */ }
  }
  // 流未正常 DONE
  const result = safeParseJudgeResult(fullText);
  yield { type: 'result', result, raw: fullText };
}
```
